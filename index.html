YOUR CONTROL

Privacy Center

Understand how CloakStudio handles your session.

Temporary local processing

Selected file objects are held in browser memory. This version does not save your files to IndexedDB or Local Storage.

Refreshing or closing the page ends the working session. Downloaded exports are stored wherever you choose to save them.

GitHub Pages delivers the application itself. We will audit application dependencies and network activity before making stronger privacy claims.
